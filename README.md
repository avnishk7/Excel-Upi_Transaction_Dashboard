# Excel-Upi_Transaction_Dashboard
# 💳 UPI Transactions Dashboard | Excel

## 📌 Project Overview

This project is an **interactive UPI Transactions Dashboard built in Microsoft Excel** to analyze and visualize **5,00,000+ UPI transaction records**.

The dashboard provides a comprehensive overview of UPI transactions by analyzing transaction volume, transaction amount, cashback, success rate, suspected fraud, transaction status, UPI applications, states, banks, and transaction types.

The main objective of this project is to transform a large raw transaction dataset into meaningful and interactive business insights using **Excel data analysis and visualization techniques**.

## 🎯 Project Objectives

The key objectives of this project are:

* Analyze more than **5 lakh UPI transaction records**
* Track the total number and value of transactions
* Monitor transaction success and failure rates
* Identify suspected fraudulent transactions
* Analyze UPI transaction trends over time
* Compare transaction amounts across different states
* Analyze the popularity of different UPI applications
* Identify the banks processing the highest transaction amounts
* Analyze transactions based on transaction type
* Explore cashback trends
* Provide interactive filtering for deeper analysis

# 📊 Dashboard Analysis

## 1️⃣ Transaction Amount Over Time

A daily trend analysis showing how the total UPI transaction amount changes throughout the month.

This visualization helps identify:

* Daily transaction patterns
* High and low transaction days
* Fluctuations in transaction amounts

The dashboard analyzes transactions performed through different UPI applications such as:

* PhonePe

* Cred Pay

This helps identify the most widely used UPI platforms.

## 3️⃣ Transactions by Status

Transactions are categorized based on their status:

* ✅ Success

* ⏳ Pending
